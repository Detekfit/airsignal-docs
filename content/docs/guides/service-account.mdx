---
title: Get a Google service account JSON
description: Get a Firebase Cloud Messaging service account JSON for AirSignal’s FCM push notification platform.
---

AirSignal sends push through **Firebase Cloud Messaging (FCM)** using a Google service account
JSON that you upload once per app. Follow the steps below to create that file.

<Callout type="info">
  This is a one-time dashboard setup step — not something your app code does. You need it
  regardless of which client SDK or platform you use.
</Callout>

<Steps>
  <Step title="Create a Firebase project">
    Open the [Firebase console](https://console.firebase.google.com) and choose
    **Get started by setting up a Firebase project** (or **Create a project**).

    ![Firebase console welcome — create a project](/assets/guides/service-account/01-firebase-start.png)

    During creation you may see **AI assistance for your Firebase project**. Turn
    **Enable Gemini in Firebase** **off** — AirSignal does not use it — then press **Continue**.

    ![Disable Gemini AI assistance for the Firebase project](/assets/guides/service-account/02-disable-ai.png)

    Next you may see **Google Analytics for your Firebase project**. Turn
    **Enable Google Analytics for this project** **off** as well — you do not need Firebase
    Analytics for AirSignal — then press **Create project**.

    ![Disable Google Analytics for the Firebase project](/assets/guides/service-account/03-disable-analytics.png)
  </Step>

  <Step title="Open Service accounts">
    After the project is ready, open **Project Overview**. Click the gear next to it, then
    choose **Service accounts**.

    ![Project Overview settings menu with Service accounts](/assets/guides/service-account/04-sidebar-service.png)
  </Step>

  <Step title="Enable Firebase Cloud Messaging API (V1)">
    In **Project settings**, open the **Cloud Messaging** tab.

    If **Firebase Cloud Messaging API (V1)** already shows a green checkmark and **Enabled**,
    you can skip the rest of this step.

    ![Cloud Messaging tab showing FCM API V1 enabled](/assets/guides/service-account/05-cloud-messaging.png)

    If it shows **Disabled**, open the **⋮** (three-dot) menu on that card →
    **Manage API in Google Cloud Console**. In Google Cloud, click **Enable** and wait until
    you see a green checkmark with **API Enabled**.

    ![Google Cloud Console — Firebase Cloud Messaging API Enabled](/assets/guides/service-account/06-enable-fcm-api.png)
  </Step>

  <Step title="Generate a new private key">
    Go back to the **Service accounts** tab. Leave **Node.js** selected (the default), then
    click **Generate new private key** and confirm.

    ![Service accounts tab — Generate new private key with Node.js selected](/assets/guides/service-account/07-generate-key.png)

    Firebase downloads a JSON file named like
    `yourproject-d4ee5-firebase-adminsdk-fbsvc-81696e9c82.json` (always a `.json` file).

    <Callout type="warning">
      Treat this file like a password. Do not commit it to source control or share it outside
      your team. AirSignal encrypts it at rest and never returns it through any API response.
    </Callout>
  </Step>

  <Step title="Upload it to AirSignal">
    In the AirSignal dashboard, create a new app (see
    [Create an app](/docs/guides/create-an-app)) or open an existing one, choose
    **Google push (Messaging)**, and upload the downloaded JSON file.
  </Step>
</Steps>

## What this unlocks

Once uploaded, AirSignal can:

- Send notifications to devices registered against this app
- Serve public Android client config via `GET /v1/config/push` (uses the same Google project)

## Rotating or replacing the credential

If the key is ever compromised, generate a new one in the Firebase console (step 4) and re-upload
it on the app — this replaces the stored credential without changing your `appId`.

## Troubleshooting

| Symptom | Likely cause |
|---|---|
| Notifications accepted but never arrive on device | Service account belongs to a different Firebase project than the one your app's push token was issued from |
| `GET /v1/config/push` missing Android fields | No Android app registered in the Firebase project yet |
| FCM sends fail after upload | Firebase Cloud Messaging API (V1) is still disabled — complete step 3 |

<Callout type="tip">
  Using the Flutter SDK? Host apps do **not** add `firebase_messaging` or ship
  `google-services.json` themselves — see the [Flutter SDK](/docs/sdks/flutter).
</Callout>
