Retrieve a notification for the project bound to your REST key, including live delivery counters.
Poll after a send to watch `status` move from `queued` / `sending` to `completed`, `partial`, or
`failed`. Scheduled messages return `scheduled` until their send time.

<Endpoint method="GET" path="/v1/notifications/{id}" />

  -H 'Authorization: Key nsk_...'
