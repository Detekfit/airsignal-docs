## Request parameter

<RequestParam name="priority" type="String" required>
  FCM priority. `normal` or `high`.
</RequestParam>

Audience — provide **exactly one** of `includeSubscriberIds`, `includeExternalIds`, or
`includedSegments` per request. Do not combine them.

<RequestParam name="includeSubscriberIds" type="String[]" required>
  Subscriber UUIDs to target (max 10 000). Use alone — not with the other audience fields.
</RequestParam>

<RequestParam name="includeExternalIds" type="String[]" required>
  Your external user ids (max 10 000). Use alone — not with the other audience fields.
</RequestParam>

<RequestParam name="includedSegments" type="String[]" required>
  Segment names. Use `["All"]` for a broadcast. Use alone — not with the other audience fields.
</RequestParam>

<RequestParam name="headings" type="Object" required>
  Localized titles (`en` recommended). Required if `contents` is omitted.
</RequestParam>

<RequestParam name="contents" type="Object" required>
  Localized body text. Required if `headings` is omitted.
</RequestParam>

<RequestParam name="name" type="String">
  Internal label for organizing messages. Not shown to recipients. Max 255 chars.
</RequestParam>

<RequestParam name="data" type="Object">
  Custom FCM data payload (max 50 keys, 8 KB).
</RequestParam>

<RequestParam name="imageUrl" type="String">
  Public `http(s)` image URL for big-picture style.
</RequestParam>

<RequestParam name="launchUrl" type="String">
  Deep link / URL opened on notification tap.
</RequestParam>

<RequestParam name="collapseId" type="String">
  Android FCM collapse key (1–128 chars).
</RequestParam>

<RequestParam name="ttl" type="Object">
  `{ "value": number, "unit": "seconds" \| "minutes" \| "hours" \| "days" }`.
</RequestParam>

<RequestParam name="androidButtons" type="Object[]">
  Up to 3 buttons: `id`, `label` required; `icon` optional.
</RequestParam>

<RequestParam name="sendAfter" type="String">
  Future ISO-8601 time with offset. Schedules the send.
</RequestParam>

<RequestParam name="deliveryMode" type="String">
  `sameTime` (default) or `perTimezone`.
</RequestParam>

<RequestParam name="localDeliveryTime" type="String">
  `HH:mm` when `deliveryMode` is `perTimezone`.
</RequestParam>
