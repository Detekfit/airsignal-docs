title: Notification events

method: POST
description: Report a click or button click for a delivered notification.
---

Records engagement for CTR and delivery reports. Only `clicked` and `buttonClicked` are accepted
— `received` is rejected. A click counts toward CTR only when it can be matched to a confirmed
delivery for that subscriber or device.

<Endpoint method="POST" path="/v1/notifications/{notificationId}/events" />

## Request parameter

<RequestParam name="notificationId" type="UUID" required>
  Notification id from the send response (`airsignalNotificationId` in the FCM data payload).
</RequestParam>

<RequestParam name="type" type="String" required>
  Event type. Allowed values: `clicked`, `buttonClicked`.
</RequestParam>

<RequestParam name="platform" type="String">
  `android`, `ios`, `web`, or `email`. Defaults to `android`.
</RequestParam>

<RequestParam name="subscriberId" type="UUID">
  Subscriber that clicked the notification.
</RequestParam>

<RequestParam name="subscriptionId" type="UUID">
  Device / push subscription UUID for per-device attribution.
</RequestParam>

<RequestParam name="buttonId" type="String">
  For `buttonClicked`, the action id matching `androidButtons[].id` (1–64 characters).
</RequestParam>
