---
title: Subscribers
description: Register devices, identify users with login/logout, and manage tags and aliases.
---

All routes on this page use `X-AirSignal-App-Id: app_...` — no REST key.

## Upsert subscriber

<Endpoint method="POST" path="/v1/subscribers" />

```request.json
{
  "subscriberId": "<persist-and-resend>",
  "subscriptionId": "<sdk-internal-device-id>",
  "pushToken": "<push-token>",
  "pushEnabled": true,
  "device": {
    "platform": "android",
    "model": "Pixel 8",
    "os": "Android 15",
    "language": "en",
    "timezone": "Asia/Dhaka"
  }
}
```

Identity resolves in this order: matching `subscriberId` → existing device by `subscriptionId` →
existing device by `pushToken` → create new. Upsert does **not** switch a device onto a different
`externalId` — use [Login](#login) for that.

<Callout type="tip">
  `subscriptionId` is SDK-internal — persist it privately per device. Never use it for send
  targeting; use `subscriberId` or `externalId` instead.
</Callout>

## Login

<Endpoint method="POST" path="/v1/subscribers/login" />

Attaches this device to the subscriber identified by `externalId`, creating the account if it
doesn't exist yet.

```request.json
{
  "externalId": "user_123",
  "subscriptionId": "<sdk-internal-device-id>"
}
```

## Logout

<Endpoint method="POST" path="/v1/subscribers/logout" />

Moves this device to a new anonymous subscriber. The identified account is kept even with zero
devices left. Does not soft-unsubscribe.

```request.json
{ "subscriptionId": "<sdk-internal-device-id>" }
```

## Heartbeat

<Endpoint method="POST" path="/v1/subscribers/{subscriberId}/heartbeat" />

Updates `lastOnlineAt`. Call periodically or on foreground.

## Tags

<Endpoint method="PUT" path="/v1/subscribers/{subscriberId}/tags" />

```request.json
{ "tags": { "plan": "pro", "cohort": "beta" } }
```

<Endpoint method="DELETE" path="/v1/subscribers/{subscriberId}/tags" />

Body: `{ "keys": ["plan"] }`.

## Aliases

<Endpoint method="PUT" path="/v1/subscribers/{subscriberId}/aliases" />

```request.json
{ "aliases": { "facebookId": "102938" } }
```

## Unsubscribe

<Endpoint method="POST" path="/v1/subscribers/{subscriberId}/unsubscribe" />

Soft opt-out. Add `?pushOnly=true` to leave the email channel untouched.

<Callout type="info">
  There is no public hard-delete route. Hard delete is available only from an authenticated
  dashboard session.
</Callout>
