---
title: Heartbeat
sidebarTitle: Heartbeat
method: POST
description: Update last online time for a subscriber.
---

Call periodically or on app foreground to refresh presence. Heartbeats also contribute to MAU
calculation.

<Endpoint method="POST" path="/v1/subscribers/{subscriberId}/heartbeat" />

<ApiMethodTabs>
  <Tab>
```bash
curl -X POST 'https://api.airsignal.dev/v1/subscribers/55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe/heartbeat' \
  -H 'Content-Type: application/json' \
  -H 'X-AirSignal-App-Id: app_...' \
  -d '{}'
```
  </Tab>
  <Tab>

## Request parameter

<RequestParam name="subscriberId" type="UUID" required>
  AirSignal subscriber id (path).
</RequestParam>

<RequestParam name="subscriptionId" type="UUID">
  Optional body field to refresh a specific push subscription.
</RequestParam>

<RequestParam name="pushToken" type="String">
  Optional body field to refresh by token.
</RequestParam>

<RequestParam name="device" type="Object">
  Optional device metadata refresh on heartbeat.
</RequestParam>
