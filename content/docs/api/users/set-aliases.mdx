title: Set aliases
sidebarTitle: Set aliases
method: PUT
description: Set alias keys on a subscriber.
---

Aliases store alternate identifiers (for example a social network id) on the subscriber.

<Endpoint method="PUT" path="/v1/subscribers/{subscriberId}/aliases" />

<ApiMethodTabs>
  <Tab>
```bash
curl -X PUT 'https://api.airsignal.dev/v1/subscribers/55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe/aliases' \
  -H 'Content-Type: application/json' \
  -H 'X-AirSignal-App-Id: app_...' \
  -d '{
    "aliases": { "facebookId": "102938" }
  }'
```
  </Tab>
  <Tab>

## Request parameter

<RequestParam name="subscriberId" type="UUID" required>
  AirSignal subscriber id (path).
</RequestParam>

<RequestParam name="aliases" type="Object" required>
  Map of alias key → value, for example `{ "facebookId": "102938" }`.
</RequestParam>
