---
title: Logout
sidebarTitle: Logout
method: POST
description: Move this device to a new anonymous subscriber without opting out of push.
---

Detaches the device from the identified account and creates a fresh anonymous subscriber for
this subscription. The identified account is kept even if it has zero devices left. Does **not**
soft-unsubscribe.

<Endpoint method="POST" path="/v1/subscribers/logout" />

```bash
curl -X POST 'https://api.airsignal.dev/v1/subscribers/logout' \
  -H 'Content-Type: application/json' \
  -H 'X-AirSignal-App-Id: app_...' \
  -d '{
    "subscriptionId": "7c2e1a90-1111-2222-3333-abcdefabcdef"
  }'
```

## Request parameter

Provide at least one device locator:

<RequestParam name="subscriptionId" type="UUID">
  SDK-internal device id to move to a new anonymous subscriber.
</RequestParam>

<RequestParam name="subscriberId" type="UUID">
  Existing AirSignal subscriber id, as an alternative locator.
</RequestParam>

<RequestParam name="pushToken" type="String">
  Device push token, as an alternative locator.
</RequestParam>
