Moves the current push subscription onto the account for `externalId`, creating the subscriber
if needed. Empty anonymous orphans may be cleaned up after transfer.

<Endpoint method="POST" path="/v1/subscribers/login" />

<ApiMethodTabs>
  <Tab>
```bash
curl -X POST 'https://api.airsignal.dev/v1/subscribers/login' \
  -H 'Content-Type: application/json' \
  -H 'X-AirSignal-App-Id: app_...' \
  -d '{
    "externalId": "user_123",
    "subscriptionId": "7c2e1a90-1111-2222-3333-abcdefabcdef"
  }'
```

## Request parameter

<RequestParam name="externalId" type="String" required>
  Your application’s user id for this account.
</RequestParam>

<RequestParam name="subscriptionId" type="UUID">
  SDK-internal device id for the subscription to attach. Provide this, `pushToken`, or
  `subscriberId`.
</RequestParam>

<RequestParam name="subscriberId" type="UUID">
  Existing AirSignal subscriber id, as an alternative device locator.
</RequestParam>

<RequestParam name="pushToken" type="String">
  Device push token, as an alternative device locator.
</RequestParam>
