Remove one or more tag keys from a subscriber.

<Endpoint method="DELETE" path="/v1/subscribers/{subscriberId}/tags" />

<ApiMethodTabs>
  <Tab>
```bash
curl -X DELETE 'https://api.airsignal.dev/v1/subscribers/55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe/tags' \
  -H 'Content-Type: application/json' \
  -H 'X-AirSignal-App-Id: app_...' \
  -d '{
    "keys": ["plan"]
  }'
```
  </Tab>
  <Tab>
