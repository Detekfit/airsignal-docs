Tags are key/value attributes you can use for segmentation and personalization.

<Endpoint method="PUT" path="/v1/subscribers/{subscriberId}/tags" />

<ApiMethodTabs>
  <Tab>
```bash
curl -X PUT 'https://api.airsignal.dev/v1/subscribers/55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe/tags' \
  -H 'Content-Type: application/json' \
  -H 'X-AirSignal-App-Id: app_...' \
  -d '{
    "tags": { "plan": "pro", "cohort": "beta" }
  }'
```
  </Tab>
  <Tab>

## Request parameter

<RequestParam name="subscriberId" type="UUID" required>
  AirSignal subscriber id (path).
</RequestParam>

<RequestParam name="tags" type="Object" required>
  Map of tag key → value, for example `{ "plan": "pro", "cohort": "beta" }`.
</RequestParam>
