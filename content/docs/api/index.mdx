The AirSignal HTTP API is split into two surfaces with different credentials. Use the REST key
only from your backend; SDKs use the public App ID.

<Cards>
  <Card title="Authentication" href="/docs/api/authentication" icon="ShieldCheck">
    App ID for collect routes, REST key for send — never mix them.
  </Card>
  <Card title="Messages" href="/docs/api/messages" icon="Send">
    Send push notifications and check delivery status.
  </Card>
  <Card title="Users" href="/docs/api/users" icon="Users">
    Register subscribers, login, logout, tags, and aliases.
  </Card>
  <Card title="Subscriptions" href="/docs/api/subscriptions" icon="Smartphone">
    Attach and update push subscriptions for a device.
  </Card>
  <Card title="Analytics" href="/docs/api/analytics" icon="BarChart3">
    Report notification clicks and engagement events.
  </Card>
</Cards>

<Callout type="info">
  All request and response JSON fields use **camelCase** (`externalId`, `pushToken`,
  `subscriberId`). Machine-readable error codes are also camelCase (`appNotFound`,
  `subscriberNotFound`).
</Callout>
