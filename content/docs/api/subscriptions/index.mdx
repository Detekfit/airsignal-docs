---
title: Subscriptions
description: Attach and update push subscriptions for a device.
---

A subscription is a channel endpoint for a subscriber — most often a push device token. Prefer
`POST /v1/subscriptions` from the SDK. Collect auth only — see
[Authentication](/docs/api/authentication).

## Endpoints

<Cards>
  <Card title="Upsert subscription" href="/docs/api/subscriptions/upsert" icon="Smartphone">
    POST — create or update a push subscription for a subscriber.
  </Card>
</Cards>

Base URL: `https://api.airsignal.dev`
