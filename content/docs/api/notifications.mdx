Routes on this page use `Authorization: Key nsk_...` — see [Authentication](/docs/api/authentication).

Always send `Content-Type: application/json`. Bodies with `text/plain` are ignored and return a validation error (`expected object, received undefined`).

## Send a notification

<Endpoint method="POST" path="/v1/notifications" />

Creates and dispatches (or schedules) a push notification for the project bound to your REST key.

### Headers

| Header | Type | | Description |
|---|---|---|---|
| `Authorization` | string | <Required /> | `Key nsk_...` (or Basic `base64(appId:nsk_...)`) |
| `Content-Type` | string | <Required /> | Must be `application/json` |
| `Idempotency-Key` | string | <Optional /> | Stable key (max 128 chars). Retries with the same key return the original notification instead of sending again |

### Body parameters

| Parameter | Type | | Description |
|---|---|---|---|
| `priority` | string | <Required /> | FCM priority. One of `normal` \| `high` |
| `includeSubscriberIds` | string[] | <Optional />* | AirSignal subscriber UUIDs (max **10 000**). Exactly **one** audience field must be non-empty on send |
| `includeExternalIds` | string[] | <Optional />* | Your app’s external user ids (max **10 000**, each 1–255 chars) |
| `includedSegments` | string[] | <Optional />* | Segment names. Use `["All"]` for a queued broadcast to every subscribed push device |
| `headings` | object | <Optional />† | Localized titles — map of locale → string (max 500 chars each, ≤ 50 locales). Prefer `en` |
| `contents` | object | <Optional />† | Localized body text — map of locale → string (max 2000 chars each, ≤ 50 locales) |
| `name` | string | <Optional /> | Internal message name (dashboard / reporting). Max 255 chars |
| `status` | string | <Optional /> | `send` (default) queues/dispatches; `draft` stores only (no FCM) |
| `data` | object | <Optional /> | Custom FCM data payload (≤ 50 keys, ≤ 8 KB JSON). Avoid reserved AirSignal keys |
| `imageUrl` | string | <Optional /> | Public `http(s)` image URL for big-picture style (max 2048 chars) |
| `launchUrl` | string | <Optional /> | URL / deep link opened on notification click (max 2048 chars) |
| `collapseId` | string | <Optional /> | FCM Android collapse key (1–128 chars) |
| `ttl` | object | <Optional /> | Time-to-live: `{ "value": number, "unit": "seconds" \| "minutes" \| "hours" \| "days" }`. `value` is a positive int ≤ **2 419 200** (seconds equivalent) |
| `androidButtons` | object[] | <Optional /> | Up to **3** action buttons. Each: `id` <Required />, `label` <Required />, `icon` <Optional /> (string lengths ≤ 64 / 64 / 128) |
| `sendAfter` | string | <Optional /> | Future ISO-8601 datetime **with offset** (e.g. `2026-07-28T12:00:00.000Z`). Sets status to `scheduled` |
| `channel` | string | <Optional /> | `push` (default) \| `email` (reserved) |
| `deliveryMode` | string | <Optional /> | `sameTime` (default) — one UTC instant; `perTimezone` — local wall clock per device |
| `localDeliveryTime` | string | Conditional | Required when `deliveryMode` is `perTimezone`. Format `HH:mm` (24h), e.g. `09:30` |

\* On `status: "send"` (the default), provide **at least one** of `includeSubscriberIds`, `includeExternalIds`, or `includedSegments`.

† On send, provide **at least one** of `headings` or `contents`.

### Example — send to subscribers

```bash
curl -X POST 'https://api.airsignal.dev/v1/notifications' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Key nsk_...' \
  -d '{
    "includeSubscriberIds": ["55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe"],
    "headings": { "en": "Order shipped" },
    "contents": { "en": "Your package is on the way." },
    "launchUrl": "https://airsignal.dev/orders/1043",
    "priority": "high",
    "data": { "orderId": "1043" }
  }'
```

```request.json
{
  "includeSubscriberIds": ["55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe"],
  "headings": { "en": "Order shipped" },
  "contents": { "en": "Your package is on the way." },
  "launchUrl": "https://airsignal.dev/orders/1043",
  "priority": "high",
  "data": { "orderId": "1043" }
}
```

### Example — broadcast to All (queued)

```request.json
{
  "includedSegments": ["All"],
  "headings": { "en": "Weekend sale" },
  "contents": { "en": "20% off everything until Sunday." },
  "imageUrl": "https://cdn.example.com/banner.png",
  "priority": "normal",
  "ttl": { "value": 3, "unit": "days" },
  "collapseId": "weekend-sale"
}
```

### Example — schedule for later

```request.json
{
  "includeExternalIds": ["user_123"],
  "headings": { "en": "Reminder" },
  "contents": { "en": "Your trial ends tomorrow." },
  "priority": "high",
  "sendAfter": "2026-07-28T12:00:00.000Z"
}
```

### Response fields

| Field | Type | Description |
|---|---|---|
| `id` | uuid | Notification id — use with `GET /v1/notifications/{id}` and engagement events |
| `status` | string | Lifecycle: `draft` \| `scheduled` \| `queued` \| `sending` \| `completed` \| `partial` \| `failed` \| `cancelled` |
| `channel` | string | `push` (or reserved `email`) |
| `targetType` | string \| null | `subscriber_ids` \| `external_ids` \| `all` (segments / All) |
| `headings` / `contents` | object | Localized text as stored |
| `data` | object | Custom payload echoed back (sanitized) |
| `priority` | string | `normal` \| `high` |
| `imageUrl` / `launchUrl` / `collapseId` | string \| null | Optional media / deep link / collapse key |
| `ttl` | object \| null | `{ "value": <seconds>, "unit": "seconds" }` when a TTL was set |
| `androidButtons` | object[] | Action buttons stored on the message |
| `scheduleMode` | string | `immediate` \| `scheduled` \| `timezone` |
| `scheduledAt` | string \| null | ISO time when scheduled / send-after |
| `deliveryMode` | string | `sameTime` \| `perTimezone` |
| `localDeliveryTime` | string \| null | `HH:mm` when using per-timezone delivery |
| `createdVia` | string | `api` for REST sends; `dashboard` for UI-created messages |
| `createdAt` / `updatedAt` | string | ISO timestamps |
| `deliveryStatus` | object | Aggregate counters (see below) |

#### `deliveryStatus`

| Field | Type | Description |
|---|---|---|
| `audience` | number | Devices targeted |
| `sent` | number | Accepted by FCM |
| `delivered` | number | Delivered count (provider success; mirrors sent when not tracked separately) |
| `failed` | number | Hard send failures |
| `unsubscribed` | number | Invalid / unsubscribed tokens encountered at send |
| `remaining` | number | Still to process |
| `capped` | number | Reserved rate/message caps |
| `clicks` | number | SDK-reported clicks |
| `clickThroughRate` | number | CTR % (`clicks / delivered * 100`) |
| `channel` | string | Delivery channel |

<Callout type="warning">
  Send can return `402 mauLimitExceeded` when the organization is frozen at its included MAU.
  Do not auto-retry plan errors — they are terminal until the plan or payment state changes.
</Callout>

## Report engagement (SDK)

<Endpoint method="POST" path="/v1/notifications/{notificationId}/events" />

Uses collect auth only — `X-AirSignal-App-Id`. The Flutter / mobile SDK calls this; you usually do not call it from your backend.

### Headers

| Header | Type | | Description |
|---|---|---|---|
| `X-AirSignal-App-Id` | string | <Required /> | Public `app_...` id |
| `Content-Type` | string | <Required /> | `application/json` |

### Body parameters

| Parameter | Type | | Description |
|---|---|---|---|
| `type` | string | <Required /> | `clicked` \| `buttonClicked` (`received` is rejected) |
| `platform` | string | <Optional /> | `android` (default) \| `ios` \| `web` \| `email` |
| `subscriberId` | uuid | <Optional /> | Subscriber that clicked |
| `subscriptionId` | uuid | <Optional /> | Device / push subscription UUID for attribution |
| `buttonId` | string | <Optional /> | Required in practice for `buttonClicked` (1–64 chars); matches `androidButtons[].id` |

```request.json
{
  "type": "clicked",
  "subscriberId": "55b8dbbf-cbf4-4ebd-9e06-8a33517a37fe",
  "subscriptionId": "7c2e1a90-1111-2222-3333-abcdefabcdef",
  "platform": "android"
}
```

A click only counts toward CTR when it can be matched to a confirmed delivery for that subscriber or device.

## Rate limits

| Scope | Budget |
|---|---|
| Collect `/v1` (`X-AirSignal-App-Id`) | 100 requests / minute per IP |
| Send `/v1/notifications` (`nsk_...`) | Free 10/s · Starter 50/s · Pro 200/s · Enterprise 500+/s |

Throttled responses are `429` with `Retry-After`.
