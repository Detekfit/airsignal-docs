<Callout type="info">
  The native iOS SDK is on the roadmap. Until it ships, use the same collect API contracts
  documented in [API Reference](/docs/api) — or the [Flutter SDK](/docs/sdks/flutter) if your app
  is Flutter-based.
</Callout>

## Planned coverage

When this guide is ready it will be a single start-to-end page covering:

1. Installation (Swift Package / CocoaPods)
2. Initialization (`appId`)
3. Identity (login / logout / `externalId`)
4. Push permissions, receive, and engagement

## Today

- Collect routes are already platform-agnostic (`device.platform: "ios"`)
- Push transport remains FCM via your uploaded
  [Google service account](/docs/guides/service-account)
