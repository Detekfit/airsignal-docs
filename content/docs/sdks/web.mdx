Save the site URL on the app's Web platform page, then add the worker and the head script on that site.

<Callout type="warning">
  The site URL is an exact https origin. `https://www.example.com` and `https://example.com` are different sites. `http://localhost` works for local testing.
</Callout>

## Setup

<Steps>
  <Step title="Upload the worker">
    Download `AirSignalSDK.js` and put it at the site root. It must open at `https://example.com/AirSignalSDK.js`.

    <DownloadAirSignalSdk />
  </Step>
  <Step title="Add the script">
    Paste this in `<head>` on every page. Replace `YOUR_APP_ID` with the public app id from app settings. Leave the script URL as written.

    ```html
    <script src="https://cdn.airsignal.dev/sdks/web/v1/airsignal.js" defer></script>
    <script>
      window.AirSignalDeferred = window.AirSignalDeferred || [];
      AirSignalDeferred.push(function (AirSignal) {
        AirSignal.init({ appId: "YOUR_APP_ID" });
      });
    </script>
    ```
  </Step>
</Steps>

A site that cannot host a file at `/AirSignalSDK.js` (for example Blogger) cannot receive web push.

After the page loads, the SDK shows a subscribe card. Subscribe opens the browser permission dialog on that origin.

## Initialization

| Argument | Default | Purpose |
|---|---|---|
| `appId` | required | Public app id from the dashboard |
| `autoPrompt` | `true` | Set `false` and call `requestPermission()` from your own button |

```html
<button onclick="AirSignalDeferred.push(function (s) { s.requestPermission(); })">
  Enable notifications
</button>
```

```js
AirSignalDeferred.push(async function (AirSignal) {
  const status = AirSignal.getPermission();
  const subscriberId = AirSignal.getSubscriberId();
});
```

`getPermission()` is `"default"`, `"granted"`, `"denied"`, or `"unsupported"`. Keep `subscriberId` if you send to that user from your backend. See [Users](/docs/api/users).

## Identity

A new browser is anonymous. Call `login` after your own sign-in.

```js
AirSignalDeferred.push(async function (AirSignal) {
  await AirSignal.login("user_123");
});
```

`login` attaches this browser to that `externalId` and creates the subscriber if needed.

```js
AirSignalDeferred.push(async function (AirSignal) {
  await AirSignal.logout();
});
```

`logout` moves this browser to a new anonymous subscriber and keeps the identified account. It does not stop push.

```js
AirSignalDeferred.push(async function (AirSignal) {
  await AirSignal.setTags({ plan: "pro", cohort: "beta" });
  await AirSignal.removeTags(["cohort"]);
});
```

## Opting in / out

```js
AirSignalDeferred.push(async function (AirSignal) {
  await AirSignal.optOut();
  await AirSignal.optIn();
});
```

`optOut` stops push for this browser. It does not change email subscription. A notification click is reported automatically.
