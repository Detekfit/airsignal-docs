title: Quickstart
description: Send your first push with the AirSignal REST API — create an app, register a device, and deliver via FCM.
---

This quickstart uses Android. For a website, configure [Web](/docs/guides/web), then follow the [Web SDK](/docs/sdks/web) or [WordPress](/docs/sdks/wordpress). The same app can reach both.

<Steps>
  <Step title="Create an Android app">
    Follow [Android](/docs/guides/android). You will get a public `appId` (`app_...`).
  </Step>
  <Step title="Register a device">
    Call the collect API with your `appId` to register a subscriber and push token:

    ```curl.sh
    curl -X POST https://api.airsignal.dev/v1/subscribers \
      -H "X-AirSignal-App-Id: app_..." \
      -H "Content-Type: application/json" \
      -d '{
        "pushToken": "<device-push-token>",
        "device": { "platform": "android" }
      }'
    ```

    The response includes a `subscriberId` — persist it on the device.
  </Step>
  <Step title="Generate a REST key">
    In **Settings** on your app, generate a project REST key (`nsk_...`). This key is used only
    for sending — never ship it inside a mobile or web client.
  </Step>
  <Step title="Send a notification">
    ```curl.sh
    curl -X POST https://api.airsignal.dev/v1/notifications \
      -H "Authorization: Key nsk_..." \
      -H "Content-Type: application/json" \
      -d '{
        "includeSubscriberIds": ["<subscriberId-from-step-2>"],
        "headings": { "en": "Hello" },
        "contents": { "en": "Your first AirSignal push" }
      }'
    ```
  </Step>
</Steps>

<Callout type="info">
  The [Android SDK](/docs/sdks/android) and [Flutter SDK](/docs/sdks/flutter) register the device for you. You still send with the REST key.
</Callout>
