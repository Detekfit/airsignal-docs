AirSignal uses these Subprocessors to run the Services. Updates follow the [DPA](/dpa). Full legal index: [/legal](/legal).

| Provider | Purpose |
| --- | --- |
| Cloud infrastructure provider(s) | Host and operate the Services |
| **Paddle** | Payments, tax, invoicing (Merchant of Record) |
| Email delivery provider | Transactional product email |
| **Google** (Firebase Cloud Messaging) | Deliver push to devices |
| **Google** (Analytics) | Website analytics when you consent |
| Support chat provider | Optional live support when you consent |
| **Google** / **GitHub** | Optional dashboard sign-in |

We do not publish hosting topology or internal system design here. Enterprise customers may request more under NDA via [legal@airsignal.dev](mailto:legal@airsignal.dev) or [sales@airsignal.dev](mailto:sales@airsignal.dev).
